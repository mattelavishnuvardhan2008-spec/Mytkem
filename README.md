# 📊 TKREC Attendance Analytics

An intuitive, lightweight web application built with Flask to fetch, analyze, and simulate student attendance records for TKR Engineering College (TKREC).

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?style=flat-square&logo=python)
![Flask](https://img.shields.io/badge/Framework-Flask-green?style=flat-square&logo=flask)
![Deployment](https://img.shields.io/badge/Deploy-Vercel-black?style=flat-square&logo=vercel)

---

## ✨ Features

- 🔐 **Transient Authentication:** Direct portal login without persistent credential storage.
- 📈 **Attendance Dashboard:** Real-time summary of total classes held, present, and absent counts.
- 🎯 **Target Calculator:** Instant computation of required consecutive classes to reach target attendance or safe skippable classes.
- 📱 **Responsive UI:** Dark-themed, mobile-friendly interface designed with custom CSS.

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Scraping & Parsing:** BeautifulSoup4, Requests
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Deployment:** Vercel / Gunicorn
